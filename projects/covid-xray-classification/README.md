# COVID X-Ray Classification: MLOps Pipeline
> Complete · Academic team project · École Liora · March to September 2026

4-class CNN (Keras) on 42,330 chest X-rays (COVID, Lung Opacity, Normal, Viral Pneumonia), with Grad-CAM interpretability: 88.2% accuracy and 0.88 macro F1 on a 1,169-image evaluation set. Built out into an MLOps pipeline with 8 containerized application services, CI/CD, MLflow, DVC, and Prometheus / Grafana monitoring.

Stack: Keras · OpenCV · Streamlit · FastAPI · DVC · MLflow · MinIO · Prometheus · Grafana · Evidently · Docker · Kubernetes manifests

GitHub: [Data-Team-DST/docker_covid](https://github.com/Data-Team-DST/docker_covid)

# Classification radiographies COVID : Pipeline MLOps
> Terminé · Projet académique d'équipe · École Liora · mars à septembre 2026

CNN 4 classes (Keras) sur 42 330 radiographies thoraciques (COVID, Opacité pulmonaire, Normal, Pneumonie virale), avec interprétabilité Grad-CAM : 88,2 % d'accuracy et F1 macro de 0,88 sur un jeu d'évaluation de 1 169 images. Développé en pipeline MLOps avec 8 services applicatifs conteneurisés, CI/CD, MLflow, DVC et monitoring Prometheus / Grafana.

Stack : Keras · OpenCV · Streamlit · FastAPI · DVC · MLflow · MinIO · Prometheus · Grafana · Evidently · Docker · manifestes Kubernetes
