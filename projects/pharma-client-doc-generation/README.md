# AI Document Generation Pipeline
> 🟢 Production · International pharmaceutical group

DOCX → Excel pipeline via the internal LLM, deployed in production for two business users. The internal LLM is driven through Playwright browser automation (scraping). Significant performance gain measured in production through iterative user feedback loops. Microservices architecture on Kubernetes (multi-region, on-premise private cloud).

**Stack:** Python · FastAPI · Playwright · Docker · Kubernetes · CI/CD · SonarQube · Checkmarx · GitOps
