# ms-template — Reusable Microservices Boilerplate
> 🔵 Template — Projet personnel

Git-cloneable project scaffold: centralized logging (dual-write with local fallback), project dashboard, SOLID compliance checker, and transversal Bash scripts. Applied to every new project.

**Stack:** Python · Flask · Docker · Bash
