## Python Data Analysis — E-Commerce Behavior
**School project · Book1 client · Pandas + Plotly + Dash**

---

### Context

Client: Book1, an e-commerce company. Objective: analyze user behavior on their website to understand conversion rates and identify drop-off points in the purchase funnel.

---

### Analysis

6 behavioral indicators extracted and analyzed:

| Indicator | What it measures |
|---|---|
| Visit-to-navigation rate | % of visits that browse beyond the homepage |
| Account creation | % of visitors who register |
| Purchase funnel stages | Navigation → selection → checkout completion |
| Usage frequency | Weekly active usage patterns |
| Referral source | Where users come from, and how it affects behavior |
| Device + cart abandonment | Device type correlated with abandonment rates |

**Pipeline:** pandas (data cleaning, aggregation, feature engineering) → matplotlib (static charts) → plotly + Dash (interactive dashboard for the jury).

---

### Outcome

Interactive dashboard presented to the jury. Key findings: conversion rates varied significantly by traffic source; mobile users had higher cart abandonment rates; mid-week sessions showed peak engagement.

**Stack:** Python · pandas · matplotlib · plotly · Dash

## Analyse de données Python — Comportement e-commerce
**Projet scolaire · Client Book1 · Pandas + Plotly + Dash**

---

### Contexte

Client : Book1, une entreprise e-commerce. Objectif : analyser le comportement des utilisateurs sur leur site web pour comprendre les taux de conversion et identifier les points de friction dans l'entonnoir d'achat.

---

### Analyse

6 indicateurs comportementaux extraits et analysés :

| Indicateur | Ce qu'il mesure |
|---|---|
| Taux visite → navigation | % des visites qui vont au-delà de la page d'accueil |
| Création de compte | % des visiteurs qui s'inscrivent |
| Étapes de l'entonnoir | Navigation → sélection → achat final |
| Fréquence d'utilisation | Tendances d'usage hebdomadaire |
| Source de référence | Origine des utilisateurs et impact sur le comportement |
| Appareil + abandon panier | Type d'appareil corrélé aux taux d'abandon |

**Pipeline :** pandas (nettoyage, agrégation, feature engineering) → matplotlib (graphiques statiques) → plotly + Dash (dashboard interactif pour le jury).

---

### Résultat

Dashboard interactif présenté au jury. Résultats clés : les taux de conversion variaient significativement selon la source de trafic ; les utilisateurs mobiles avaient des taux d'abandon de panier plus élevés ; les sessions en milieu de semaine montraient le pic d'engagement.

**Stack :** Python · pandas · matplotlib · plotly · Dash
